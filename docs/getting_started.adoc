== Spock Example Project

To try Spock in your local environment, clone or download/unzip the {spock-example-project}[Spock Example Project].
With a JDK 17 or newer, run the example specifications using the Gradle wrapper (`./gradlew clean test`) or the Maven wrapper (`./mvnw clean test`).
The project also includes an Ant build, which requires Ant 1.10.6 or newer and the `ant-optional` package.
See the README for IDE setup.
